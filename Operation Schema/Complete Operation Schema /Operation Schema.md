| ID | Pre-condition | Operation | Post-condition |
| OP-01 | Chamber is powered on and initialization has finished. | performSelfCheck | Every essential sensor and environmental-control device has a recorded pass/fail status. If all passed, the chamber may enter MONITORING. If any failed, conservation stays blocked and the operator is informed. |
| OP-02 | Self-check has passed. An artifact has been placed in the chamber. No other artifact is registered. | registerArtifact | The artifact's ID, name, type, condition and required limits (temperature, humidity, light, vibration) are stored. The artifact's environmental profile is loaded and ready for monitoring. |
| OP-03 | Door sensor passed the self-check. | verifyDoorStatus | The current door status (OPEN or CLOSED) is known. If the door is open, conservation is not activated. If closed, this condition is satisfied for starting conservation. |
| OP-04 | Self-check has passed. Sensors are working. | monitorEnvironment | Up-to-date temperature, humidity, light and vibration readings are available and compared with the artifact's profile. Any out-of-range reading is recorded. |
| OP-05 | Conservation is active. Temperature is outside the permitted range. Door is closed. | adjustTemperature | A heating or cooling command has been issued and the correction device is running. The violation stays open (recovery is not assumed) until verified. |
| OP-06 | Conservation is active. Humidity is outside the permitted range. Door is closed. | adjustHumidity | A humidifying or dehumidifying command has been issued and the device is running. The violation stays open (recovery is not assumed) until verified. |
| OP-07 | A temperature or humidity correction command has been issued. Sensors are working. | verifyEnvironmentalRecovery | If sensor readings are back within range, the violation is closed and conservation continues. If not back within the recovery period, the system moves to PROTECTION_MODE. |
| OP-08 | The system has entered protection mode (recovery period expired). | generateAlert | The operator has been notified of the problem and the reason. The alert is recorded. Monitoring continues. |
| OP-09 | An artifact is inside the chamber. Vibration exceeds the permitted threshold. | suspendForVibration | Activities that could risk the artifact are halted. The vibration level is recorded. The system is in VIBRATION_RESPONSE. |
| OP-10 | The system is in VIBRATION_RESPONSE. Vibration sensor is working. | verifyVibrationStabilization | If vibration stayed below the threshold for the full stabilization period, and sensors and artifact are OK, normal conservation may resume. Otherwise the system stays in VIBRATION_RESPONSE. |
| OP-11 | Conservation is active. The door is opened. | suspendOnDoorOpen | Normal conservation is stopped immediately and the event is recorded. Monitoring continues. Conservation does not resume automatically when the door closes. It resumes only after sensor, artifact, temperature and humidity checks pass. |
| OP-12 | Main power is lost. Emergency power is available. | switchEmergencyPower | The chamber runs on emergency power. The transition is recorded. Essential monitoring and protection continue. Return to main power only after it is verified as available. |
| OP-13 | Main power is lost. Emergency power is NOT available. | performSafeShutdown | Non-essential equipment is stopped and the artifact is kept as safe as possible. The incident is logged. The system is in SAFE_SHUTDOWN. |
| OP-14 | Operator requests artifact removal. | authorizeArtifactRemoval | If the chamber is safe (no protection response, no unresolved violation, no active vibration response, checks passed), removal is approved. Otherwise it is rejected, the reason is recorded and the operator is notified. |
